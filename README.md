# 😈 Judge Me AI

An AI-powered app that roasts, analyzes, and improves your bio, resume, or profile.
This app uses persona-based prompt engineering to perform zero-shot personality analysis.

### Features
- Adjustable honesty (Gentle → Brutal)
- Context-aware judgment
- Personality insights
- Actionable improvement tips

### Tech Stack
- Streamlit
- Groq 
- Prompt Engineering
